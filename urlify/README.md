# URLify

Projeto vazio criado com Java 8, Maven e Spring Boot 2.7.18 para praticar o
algoritmo `URLify`.

## Estrutura principal

- `UrlifyApplication`: inicialização do Spring Boot.
- `Urlify`: classe onde o algoritmo deve ser implementado.

## Executar os testes

```shell
mvn test
```

## Executar a aplicação

```shell
mvn spring-boot:run
```
