# StringUniqueCharacters

Projeto vazio criado com Java 8, Maven e Spring Boot 2.7.18 para praticar o
algoritmo `StringUniqueCharacters`.

## Estrutura principal

- `StringUniqueCharactersApplication`: inicialização do Spring Boot.
- `StringUniqueCharacters`: classe onde o algoritmo deve ser implementado.

## Executar os testes

```shell
mvn test
```

## Executar a aplicação

```shell
mvn spring-boot:run
```
